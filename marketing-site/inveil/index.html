Oriel — a calm view of the web

A native browser for iPhone, iPad, and Mac, built with Swift, SwiftUI, and WebKit — not a Chromium shell. Process-shared WebKit, system materials, and chrome that stays out of the way.

  • One app across iOS, iPadOS, and macOS
  • Oriel Shields: EasyList, AdGuard-derived filters, tracker hosts
  • Open source under Apache 2.0
